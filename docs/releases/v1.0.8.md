## Kuota v1.0.8

<!-- kuota:es -->

### Cambios principales

- Kuota reconoce tanto el nuevo nombre ChatGPT Desktop como el nombre anterior Codex Desktop al cambiar de cuenta.
- En macOS, Kuota cierra y reabre la aplicación mediante el bundle estable `com.openai.codex`, evitando que el cambio de cuenta intente abrir una aplicación que ya no existe con el nombre anterior.
- En Windows, Kuota detecta `ChatGPT.exe` y `Codex.exe`, conserva la ruta real de la aplicación activa y verifica que vuelva a ejecutarse después del cambio.
- Las sesiones activas de Codex CLI permanecen intactas durante el reinicio de Desktop.
- Se añadieron nuevos bugs para solucionar en proximas versiones.

### Assets

- Build universal para macOS.
- Instaladores para Windows x64.
- `latest.json` para el actualizador automatico.

<!-- kuota:en -->

### Main Changes

- Kuota recognizes both the new ChatGPT Desktop name and the previous Codex Desktop name when switching accounts.
- On macOS, Kuota quits and reopens the app through the stable `com.openai.codex` bundle, preventing account switching from trying to open an app that no longer exists under its previous name.
- On Windows, Kuota detects `ChatGPT.exe` and `Codex.exe`, preserves the real path of the active app, and verifies that it is running again after the switch.
- Active Codex CLI sessions remain untouched while restarting Desktop.
- New bugs were added to be fixed in future versions.

### Assets

- Universal macOS build.
- Windows x64 installers.
- `latest.json` for the automatic updater.
