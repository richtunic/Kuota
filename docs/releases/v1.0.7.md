## Kuota v1.0.7

<!-- kuota:es -->

### Cambios principales

- Regresa la cuota de 5 horas para cualquier plan que reporte un porcentaje valido; respuestas como `401`, `N/A` o `RequestFailed` no se muestran como cuotas.
- Ajustes permite activar o desactivar el cambio automatico de cuenta.
- El cambio automatico ahora es estricto: solo selecciona otra cuenta cuando su cuota semanal es conocida y mayor que `0%`, y su cuota de 5 horas tambien es valida y mayor que `0%` cuando esa ventana esta presente. Si ninguna cuenta cumple, no cambia nada.
- Kuota detecta localmente el agotamiento reportado por las sesiones de Codex y reacciona sin consultar la API cada segundo; el refresco de 60 segundos permanece como respaldo.
- La pantalla principal tiene mas altura para mostrar ambas cuotas sin scroll interno y Ajustes mantiene su propio desplazamiento cuando lo necesita.
- La actividad y las fechas de reinicio se muestran en español, incluyendo formatos como `Ahora`, `hace 2 h` y `00:26 el 1 sep`.
- Se añadieron nuevos bugs para solucionar en proximas versiones.

### Assets

- Build universal para macOS.
- Instaladores para Windows x64.
- `latest.json` para el actualizador automatico.

<!-- kuota:en -->

### Main Changes

- The five-hour quota is back for any plan that reports a valid percentage; responses such as `401`, `N/A`, or `RequestFailed` are not displayed as quotas.
- Settings can enable or disable automatic account switching.
- Automatic switching is now strict: another account is selected only when its weekly quota is known and above `0%`, and its five-hour quota is also valid and above `0%` when that window is present. If no account qualifies, nothing changes.
- Kuota detects locally reported Codex session exhaustion and reacts without querying the API every second; the 60-second refresh remains as a fallback.
- The main window is taller so both quotas fit without internal scrolling, while Settings keeps its own scrolling when needed.
- Activity and reset dates are localized in Spanish, including formats such as `Ahora`, `hace 2 h`, and `00:26 el 1 sep`.
- New bugs were added to be fixed in future versions.

### Assets

- Universal macOS build.
- Windows x64 installers.
- `latest.json` for the automatic updater.
