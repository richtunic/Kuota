## Kuota v1.0.5

<!-- kuota:es -->

### Cambios principales

- Windows ya no depende de `cmd.exe` ni shims `.cmd` para cambiar de cuenta: `codex-auth switch`, `status`, `list` y `--version` se ejecutan mediante `node.exe` y el script real de `codex-auth`.
- Después de cambiar cuenta en Windows, Kuota intenta cerrar y reabrir Codex automáticamente usando la ruta real del `Codex.exe` que estaba corriendo, verificando que vuelva a quedar abierto con varios métodos de arranque.
- La app ahora revisa nuevas versiones publicadas en GitHub Releases y, si existe una actualización, muestra un diálogo antes de descargarla.
- El diálogo de actualización muestra la versión actual, la nueva versión y los cambios de la release en el idioma activo de Kuota.
- El usuario puede actualizar ahora u omitir la actualización por el momento.
- Ajustes y Acerca de Kuota incluyen una invitación para regalarle un Rokaccino al desarrollador, con botón localizado que abre Ko-fi en el navegador del sistema.

### Assets

- Build universal para macOS.
- Instaladores para Windows x64.
- `latest.json` para el actualizador automatico.

<!-- kuota:en -->

### Main Changes

- Windows no longer depends on `cmd.exe` or `.cmd` shims to switch accounts: `codex-auth switch`, `status`, `list`, and `--version` now run through `node.exe` and the real `codex-auth` script.
- After switching accounts on Windows, Kuota now tries to close and reopen Codex automatically using the real path of the running `Codex.exe`, verifying that it is running again with multiple launch methods.
- The app now checks GitHub Releases for new Kuota versions and shows a dialog before downloading an update.
- The update dialog shows the current version, the new version, and release changes in Kuota's active language.
- Users can update now or skip the update for the moment.
- Settings and About Kuota now include a Rokaccino support note for the developer, with a localized button that opens Ko-fi in the system browser.

### Assets

- Universal build for macOS.
- Windows x64 installers.
- `latest.json` for the automatic updater.
