## Kuota v1.0.10

<!-- kuota:es -->

### Cambios principales

- Corrige el error "npm no está instalado o no está en PATH" para usuarios que usan `fnm` (y `volta`). Kuota ahora encuentra `npm`/`node` aunque la app se abra desde el menú/bandeja sin heredar el `PATH` del shell.
- Compatible con instalaciones `fnm` en `APPDATA/fnm`, `LOCALAPPDATA/fnm`, `~/.local/share/fnm`, `~/.fnm` y variables `FNM_DIR`/`FNM_MULTISHELL_PATH`, incluyendo layouts `aliases/default` (Windows) y `aliases/default/bin` (Unix).
- Incluye el soporte de cuotas `codex-auth 0.3.0` de v1.0.9.
- Se añadieron nuevos bugs para solucionar en próximas versiones.

### Assets

- Build universal para macOS.
- Instaladores para Windows x64.
- `latest.json` para el actualizador automático.

<!-- kuota:en -->

### Main Changes

- Fixes "npm not installed or not in PATH" for users on `fnm` (and `volta`). Kuota now finds `npm`/`node` even when launched from menu/tray without inheriting shell `PATH`.
- Compatible with `fnm` installs in `APPDATA/fnm`, `LOCALAPPDATA/fnm`, `~/.local/share/fnm`, `~/.fnm` and `FNM_DIR`/`FNM_MULTISHELL_PATH` vars, including both `aliases/default` (Windows) and `aliases/default/bin` (Unix) layouts.
- Includes v1.0.9 `codex-auth 0.3.0` quota support.
- New bugs were added to be fixed in future versions.

### Assets

- Universal macOS build.
- Windows x64 installers.
- `latest.json` for the automatic updater.
