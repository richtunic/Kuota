## Kuota v1.0.10

<!-- kuota:es -->

### Correcciones

- Kuota detecta la cuenta activa desde el estado actual de `codex-auth`, evitando conservar una marca activa anterior.
- Las cuentas borradas en Kuota permanecen ocultas después de actualizar o reiniciar, incluso si fueron detectadas por `codex-auth`.
- Al completar el login por código, Kuota actualiza la lista al instante y reintenta a los 5, 15 y 45 segundos si la cuenta tarda en aparecer.
- Se añadieron nuevos bugs para solucionar en proximas versiones.

### Builds

- Build universal para macOS.
- Instaladores para Windows x64.
- `latest.json` para el actualizador automático.

<!-- kuota:en -->

### Fixes

- Kuota reads the active account from the current `codex-auth` state instead of retaining a stale active marker.
- Accounts removed from Kuota remain hidden after refresh or restart, including accounts discovered through `codex-auth`.
- After device-code login, Kuota refreshes the account list immediately and retries after 5, 15, and 45 seconds if the account takes longer to appear.
- New bugs were added to be fixed in future versions.

### Builds

- Universal macOS build.
- Windows x64 installers.
- `latest.json` for the automatic updater.
