## Kuota v1.0.6

<!-- kuota:es -->

### Cambios principales

- Kuota ahora muestra solamente la cuota semanal restante de Codex y deja de mostrar la antigua ventana de 5 horas.
- Se conserva compatibilidad interna con versiones de `codex-auth` que todavia incluyan la columna de 5 horas, sin exponerla en la interfaz.
- Se añadieron nuevos bugs para solucionar en proximas versiones.

### Assets

- Build universal para macOS.
- Instaladores para Windows x64.
- `latest.json` para el actualizador automatico.

<!-- kuota:en -->

### Main Changes

- Kuota now shows only the remaining weekly Codex quota and no longer displays the former five-hour window.
- Internal compatibility is preserved for `codex-auth` versions that still include the five-hour column, without exposing it in the interface.
- New bugs were added to be fixed in future versions.

### Assets

- Universal build for macOS.
- Windows x64 installers.
- `latest.json` for the automatic updater.
