## Kuota v1.0.11

<!-- kuota:es -->

### Corrección

- Después de completar el login por código, Kuota muestra la cuenta autenticada aunque se hubiera ocultado antes al borrarla localmente.
- Las demás cuentas que quitaste siguen ocultas; iniciar sesión restaura solo la cuenta activa y las cuentas nuevas detectadas durante ese flujo.
- Se añadieron nuevos bugs para solucionar en proximas versiones.

### Builds

- Build universal para macOS.
- Instaladores para Windows x64.
- `latest.json` para el actualizador automático.

<!-- kuota:en -->

### Fix

- After device-code login, Kuota shows the authenticated account even if it had previously been hidden when removed locally.
- Other removed accounts remain hidden; login restores only the active account and new accounts detected during that flow.
- New bugs were added to be fixed in future versions.

### Builds

- Universal macOS build.
- Windows x64 installers.
- `latest.json` for the automatic updater.
