## Kuota v1.0.12

<!-- kuota:es -->

### Corrección

- Kuota espera a que ChatGPT o Codex termine de cerrarse y comprueba que la aplicación vuelva a abrirse después de cambiar de cuenta.
- Si no puede reabrirla, muestra un error claro en lugar de dejar el cierre sin explicación.
- Se añadieron nuevos bugs para solucionar en proximas versiones.

### Builds

- Build universal para macOS.
- Instaladores para Windows x64.
- `latest.json` para el actualizador automático.

<!-- kuota:en -->

### Fix

- Kuota waits for ChatGPT or Codex to finish closing and verifies that the app reopens after switching accounts.
- If it cannot reopen the app, Kuota reports a clear error instead of silently leaving it closed.
- New bugs were added to be fixed in future versions.

### Builds

- Universal macOS build.
- Windows x64 installers.
- `latest.json` for the automatic updater.
